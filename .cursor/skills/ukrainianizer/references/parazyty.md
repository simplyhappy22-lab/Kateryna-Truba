# Слова-паразити

Слова, які нічого не додають реченню: прибери — і сенс не зміниться, а текст стане на кілька відсотків коротшим і на порядок певнішим у собі.

Не плутати з сусідніми словниками. Тут лише те, чого в них немає:

- **порожні зачини** («важливо зазначити», «варто підкреслити») → [ai-patterns.md](ai-patterns.md)
- **канцелярські зв'язки** («на даний момент», «у зв'язку з тим, що») → [kancelyaryzmy.md](kancelyaryzmy.md)
- **подвоєні значення** («кінцевий результат», «цілком і повністю») → [pleonazmy.md](pleonazmy.md)

## ⚠️ Спершу прочитай це

`SKILL.md` радить додавати частки — **ж, бо, от, та, адже** — щоб текст звучав живо. Класичні переліки паразитів вимагають ті самі слова викидати.

Обидві поради правильні. Різниця не в слові, а в роботі, яку воно виконує.

| Робота | Приклад | Вирок |
|---|---|---|
| Частка тримає наголос | «Це ж очевидно» | Лишити |
| Частка зв'язує причину | «Не пішла, бо дощ» | Лишити |
| Частка вказує | «От де собака заритий» | Лишити |
| Слово стоїть на початку й не несе нічого | «Ну, от, значить, почнемо» | Викинути |

**Перевірка одним рухом:** прибери слово й перечитай речення вголос. Змінився наголос або зміст — це частка. Не змінилося нічого — паразит.

## 1. Паразити усного мовлення

У розмові вони дають час подумати. На письмі часу думати не треба — читач бачить готове речення.

| ❌ Паразит | ✅ Що робити |
|---|---|
| ну | викинути |
| от, ото (на початку речення) | викинути |
| значить, значиться | викинути |
| коротше, коротше кажучи | викинути або «отже» |
| типу, типу того | «на кшталт», «щось на зразок» |
| як би, якби так | викинути |
| це саме, як його | викинути |
| знаєш, розумієш, бачиш | викинути |
| так би мовити | викинути |
| як то кажуть | викинути або назвати, хто каже |
| скажімо так | викинути |
| в принципі | викинути |

Осібно стоїть **«коротше»**. У [rusyzmy.md](rusyzmy.md) воно подане як правильна заміна російському «короче» — і це так. Але правильне слово на місці паразита лишається паразитом. У живій мові доречне, у тексті — ні.

**До:**
> Ну, коротше, ми, значить, спробували типу нову схему, і воно, як би, спрацювало.

**Після:**
> Ми спробували нову схему. Спрацювало.

## 2. Книжкові паразити

Найпідступніші. Вони звучать розумно, тому рука не піднімається їх стерти, а редактор лишає їх у тексті з відчуттям, що прибрав би щось важливе. Насправді вони не несуть нічого.

| ❌ Паразит | ✅ Що робити |
|---|---|
| власне, власне кажучи | викинути |
| насправді | лишити, тільки якщо далі йде спростування |
| фактично | викинути або дати факт |
| по суті, по суті кажучи | викинути |
| по великому рахунку | викинути |
| як відомо | викинути або назвати джерело |
| зрозуміло, що | викинути |
| очевидно, що | викинути або довести |
| зазначу, що | викинути |
| що стосується Х, то | «Х…» |
| не секрет, що | викинути |

Про **«насправді»** окремо, бо воно частіше за інші прикидається корисним. Це слово має роботу: спростовувати попереднє. «Усі думають, що дорого. Насправді це коштує тридцять гривень» — працює. «Насправді я вважаю, що варто спробувати» — паразит, бо нічого не спростовує.

**До:**
> Власне, по суті, тут фактично та сама проблема, що й раніше. Як відомо, це впливає на результат.

**Після:**
> Тут та сама проблема, що й раніше. За даними торішнього звіту, вона з'їдає близько чверті часу.

## 3. Підсилювачі, які послаблюють

Парадокс: що більше підсилювачів, то слабше речення. «Дуже великий» менший за «величезний», бо читач бачить не розмір, а вагання автора.

| ❌ Підсилювач | ✅ Що робити |
|---|---|
| дуже + прикметник | взяти сильніше слово: дуже великий → величезний |
| досить, доволі | викинути |
| вельми | викинути |
| абсолютно, повністю, цілком | викинути |
| реально, буквально | викинути |
| просто (як підсилювач) | викинути |
| прямо-таки | викинути |
| надзвичайно, неймовірно | замінити цифрою |

Найкраща заміна підсилювача — не сильніше слово, а число. «Дуже швидко» слабше за «за чотири секунди».

**До:**
> Це реально дуже сильно вплинуло на абсолютно всі показники.

**Після:**
> Це підняло конверсію з 2% до 7%.

## 4. Хеджування

Пом'якшувачі, за якими автор ховається від власного твердження. Один у тексті — обережність. Три поспіль — автор не знає, що каже.

| ❌ Пом'якшувач | ✅ Що робити |
|---|---|
| певною мірою | викинути |
| свого роду | викинути |
| у якомусь сенсі | викинути |
| можна сказати, що | викинути |
| десь, приблизно (про неточне) | дати межі: «від 30 до 40» |
| начебто, ніби, нібито | викинути або назвати, хто стверджує |
| як мені здається | «я вважаю» або викинути |
| ймовірно, можливо, мабуть | лишити **один** на абзац |
| має тенденцію до | «зазвичай» |

**Правило щільності:** не більше одного пом'якшувача на речення й не більше трьох на абзац. Стос із трьох у межах двадцяти слів («можливо, певною мірою це ймовірно вплине») — верхівка списку на видалення.

Не плутай із чесною непевністю. «Чесно, я не знаю» — сильне речення. «Можна сказати, що це певною мірою ймовірно» — порожнє.

**До:**
> Можна сказати, що цей підхід певною мірою, ймовірно, міг би якось вплинути на результат.

**Після:**
> Не знаю, чи спрацює. Перевірю на двох постах і скажу.

## Механічна перевірка

```python
import re

PARAZYTY = [
    "ну", "от", "ото", "значить", "коротше", "типу", "як би", "це саме",
    "знаєш", "розумієш", "так би мовити", "як то кажуть", "скажімо так",
    "власне", "фактично", "по суті", "по великому рахунку", "як відомо",
    "в принципі", "не секрет", "зазначу",
    "досить", "доволі", "вельми", "абсолютно", "повністю", "цілком",
    "реально", "буквально", "прямо-таки",
    "певною мірою", "свого роду", "у якомусь сенсі", "можна сказати",
    "начебто", "нібито", "ймовірно", "можливо", "мабуть",
]

def znajty(text):
    slova = len(re.findall(r"[а-яіїєґ']+", text.lower()))
    znajdeni = []
    for p in PARAZYTY:
        n = len(re.findall(rf"\b{re.escape(p)}\b", text.lower()))
        if n:
            znajdeni.append((p, n))
    shchilnist = sum(n for _, n in znajdeni) / max(slova, 1) * 100
    return sorted(znajdeni, key=lambda x: -x[1]), round(shchilnist, 2)
```

**Пороги щільності:**

| Показник | Оцінка |
|---|---|
| до 0,5% | чисто |
| 0,5–1,5% | норма для живого тексту |
| понад 1,5% | чистити |

Скрипт бере слова буквально й не бачить контексту, тому «от» і «можливо» він порахує завжди. Це не вирок, а місце, куди подивитися очима. Остаточне рішення — за перевіркою з початку файлу: прибрати слово й перечитати вголос.

## Чого не робити

- ❌ **Вичищати все під нуль.** Текст без жодної частки читається як інструкція до пральної машини. Ціль — 0,5–1,5%, а не нуль.
- ❌ **Прибирати частки, що тримають наголос.** «Це ж очевидно» і «Це очевидно» — різні речення.
- ❌ **Плутати хеджування з чесністю.** Автор, який визнає, що не знає, сильніший за автора, який удає впевненість.
- ❌ **Замінювати паразит на синонім.** «Певною мірою» → «до певної міри» нічого не лікує. Викидати, а не переставляти.
