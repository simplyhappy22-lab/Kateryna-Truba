# Notion: база «Контент-план»

Та сама сторінка `Катя — контент`. **Друга база**, не нові колонки в «Банк тем».

**Ім’я бази:** `Контент-план` (ще не жива). Таблицю Рілси від 30.08 видалено.  
**Relation:** властивість `Ідея` → база `Банк тем`. Без ToV в задачі не розгортати.

## Колонки

| Колонка | Тип | Навіщо |
|---|---|---|
| Одиниця | Title | коротко, як файл: «Reel — знаю і не починаю» |
| Ідея | Relation | рядок з Банку тем |
| Формат | Select | Reel / карусель |
| Що хочу сказати | Text | **тільки Катя**. Без цього бот не розгортає |
| Хук 1 | Text | |
| Прийом 1 | Select | питання / цифра / було-стало / визнання / провокація |
| Хук 2 | Text | |
| Прийом 2 | Select | те саме |
| Хук 3 | Text | |
| Прийом 3 | Select | те саме |
| Обраний хук | Select | 1 / 2 / 3 / ще не вибрала |
| Підпис | Text | під Reel або під карусель |
| Слайд 1 | Text | лише карусель |
| Слайд 2 | Text | обіцянка |
| Слайд 3 | Text | |
| Слайд 4 | Text | |
| Слайд 5 | Text | |
| Слайд 6 | Text | сенс |
| Слайд 7 | Text | CTA |
| Статус одиниці | Select | чекає 20 хв / чернетка бота / хук обрано / можна знімати |

На телефоні зроби вид **«Знімати»**: фільтр статус = хук обрано або можна знімати. У цьому виді ховай слайди 3–5, щоб не скролити простирадло.

Вид **«Чекає мене»**: «Що хочу сказати» порожнє. Це твої 20 хвилин.

Якщо стратег ще не вміє створити другу базу — імпорт [content-plan.csv](content-plan.csv), потім руками додай Relation на Банк тем (імпорт CSV relation сам не зліпить).
