# Автомат: банк → рілси

Друга таблиця: [Рілси](https://app.notion.com/p/8b3c6acf57be4bb0a384d1f3e1008cbd)  
Як заповнювати: [Як Сакура робить рілси](https://app.notion.com/p/3cc4e56ef35681409562eab1322047f8)

Катю не питають, які теми брати. Новий рядок розвідки → новий рядок рілса.

---

## Шефу (після перевірки банку)

```
Запам’ятай наступний крок після перевірки таблиці Банк тем.

Якщо в Банку за сьогодні є нові рядки розвідки (Threads / Reels / YouTube) — одразу пиши @Сакура і встав текст «Задача Сакурі» нижче. Не питай Катю, які теми брати. Не обирай сам «найкращі три». Не пиши рілси сам.

Після відповіді Сакури відкрий https://app.notion.com/p/8b3c6acf57be4bb0a384d1f3e1008cbd
Порахуй нові рядки. Не коригуй хуки.

Каті:
✓ Банк → скільки нових
✓ Рілси → скільки чернеток
✓ якщо цифри роз’їхались — де діра
```

---

## Текст, який шеф копіює Сакурі

```
Запам’ятай як «Задача Сакурі». Ти його надсилаєш @Сакура, не виконуєш.

———
Ти Сакура. Не шукаєш. Катю не питаєш, які теми брати.

Відкрий Банк тем, вид Розвідка:
https://app.notion.com/p/619f329526ca44d5a000a6690a5366a7
Бери всі НОВІ рядки за сьогодні (Threads / Reels / YouTube). Усі. Не відсіюй «на смак».

На кожен, якого ще немає в таблиці Рілси, створи ОДИН новий рядок тут:
https://app.notion.com/p/8b3c6acf57be4bb0a384d1f3e1008cbd
Як заповнювати: https://app.notion.com/p/3cc4e56ef35681409562eab1322047f8

Формат = Reel. Статус = чернетка. Зв’яжи Ідея з рядком банку.

Заповни: Одиниця, Хук 1, Хук 2, Хук 3, Сценарій, Кадри, Текст на екрані, Підпис, CTA.
Три хуки — три різні прийоми, не синоніми. Перші 2 секунди зупиняють скрол.
Сценарій 20–40 сек: хук → жива сцена → поворот → мікродія. Голос Каті, ви. Не коуч. Не копія оригіналу.
CTA: ТЕСТ / зберегти / серія / коментар. Не «купи».
Не публікуй. Банк тем не переписуй.

Якщо нових у банку немає — напиши «немає нових». Не вигадуй теми.

Шефу: скільки рілсів додано / скільки пропущено бо вже були / чи порожньо.
———
```
