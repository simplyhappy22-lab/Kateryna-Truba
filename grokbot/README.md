# Інструкції для агентів Grok Bot

Grok Bot **не пише інструкції сам**. Він створює агента з ім’ям, посадою й коротким описом. Усе, як бот має працювати щодня, треба прописати вручну.

Це нормально. Так і задумано в [офіційній документації](https://docs.x.ai/grok-bot/bots):

- **Опис у профілі** — постійні правила, межі, зона відповідальності.
- **Повідомлення в чаті** — конкретне завдання («напиши 7 хуків на цей бриф»).
- **Skill** — повторюваний процес, який бот має робити однаково щоразу.

## Що робити зараз

1. Відкрий бота → **View conversation details** → **Agent settings** (або **Edit Profile**).
2. Встав **ім’я, посаду й опис** з картки нижче.
3. У першому повідомленні цьому боту встав **стартове повідомлення** з тієї ж картки. Це навчає його робочому процесу.
4. Коли процес відпрацює 1–2 рази — попроси бота зберегти його як **skill**.
