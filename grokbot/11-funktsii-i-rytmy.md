# Як увімкнути функції зі скрінів (Routines, екран, команда)

У Grok Bot **немає окремої форми «зроби як у демо»**. Ті самі речі з’являються з трьох місць:

1. **Чат** — ти пишеш, що робити і коли. Бот сам створює Routine.
2. **Settings → Plugins** — підключаєш Calendar, Gmail, Drive, Sheets.
3. **Settings → Timezone** — постав **Europe/Kyiv**, інакше ранкові брифінги прийдуть не тоді.

Права колонка «Routines» і міні-екран агента **не налаштовуються окремим меню**. Екран з’являється, коли бот працює на своєму комп’ютері. Routine з’являється після фрази «кожен будень о …».

Офіційно: спочатку зроби задачу **один раз руками в чаті**. Якщо результат ок — «збережи як skill». Потім — постав на розклад. Не став розклад на те, що ще жодного разу не вийшло.

---

## Що є на скрінах і хто це в тебе

Не клонуй чужі ролі (Sales Outbound, Talent Scout, Expense). Візьми механіку.

| На скріні | У тебе | Що повторювати |
|---|---|---|
| Chief + morning briefing | Координаторка | Ранковий статус: зроблено / треба «так-ні» |
| End-of-week recap | Координаторка | П’ятниця: що зрушило гроші / продукт / зйомку |
| Overnight outbound | UGC-команда | Раз на тиждень: 5 оферів, нічого не надсилати |
| Inbox sweep | Інбокс (пізніше) | Ранок: 5 рядків «варто», решта шум |
| Account / Talent / Expense | не створювати | Інша робота |
| Offsite crew | група «Контент-відділ» | 6 ролей, конвеєр Threads: [kontent-viddil/README.md](kontent-viddil/README.md) |
| «Memory updated» | будь-який бот | Після правки: «запам’ятай це як правило» |
| Agent’s screen | кожен бот | Відкривається сам, коли бот лізе в браузер / Drive |

## Крок 0. Раз у Settings

1. **Timezone = Europe/Kyiv**
2. **Notifications** увімкни в Координаторки й Контенту (View conversation details → Agent settings).
3. **Plugins:** Google Calendar, Gmail, Google Drive. Якщо є — Sheets.
4. У чаті пиши `@` щоб прикріпити конектор, `/` щоб викликати skill.

Логін у браузері бота робиться **один раз**. Сесія спільна для всіх твоїх ботів. Паролі в чат не кидай: якщо просить увійти — відкрий його екран і зайди сама.

## Як писати задачу (формула зі скрінів)

Одне повідомлення, п’ять рядків. Не есе.

```
Мета: [що має лежати готовим]
Звідки брати: [Drive / Календар / Gmail / цей файл]
Зроби сам: [що можна без мене]
Мені на стіл: [лише рішення так/ні або зйомка]
Не робити: [не публікувати / не слати / не видаляти]
```

Приклад для Контенту:

```
Мета: сценарій завтрашнього Reel з 14-денного плану.
Звідки: Drive / Grok / Контекст Каті / план 14 днів.
Зроби сам: обери день, напиши хук + кадри + Stories + CTA.
Мені на стіл: один день для зйомки, не тиждень.
Не робити: не публікувати.
```

## Формат відповіді (як у Chief)

Встав це в опис **кожного** бота або надішли раз Координаторці:

```
Коли звітуєш — коротко, як ранок у Chief:

✓ [зона] → що зроблено (факт)
✓ [зона] → що зроблено
Сьогодні треба від Каті: максимум 2 пункти «так/ні» або одна зйомка.
Все інше закрито.

Нічого не надсилати, не публікувати, не бронювати, не купувати без явного «так».
Чернетки тримай. Якщо джерела немає — напиши «немає даних», не вигадуй.
```

## Skills (кнопка «збережи як skill»)

Коли бот **один раз** зробив добре:

```
Збережи цей процес як skill «[назва]».
Включи: звідки брати, кроки, формат відповіді, що потребує мого «так».
```

Назви, які тобі потрібні:

- `Ранковий бриф`
- `Пакет Reels на тиждень`
- `5 UGC-оферів`
- `Розбір пошти Skool`
- `Повістка 12 тижнів`

Якщо skill не видно в `/` — Settings → Plugins → Yours → увімкни для цього бота.

**Teach a task** (якщо є в чаті один-на-один): відкрий екран бота → Teach a task → покажи кліками до 10 хвилин → перевір skill → лише потім Routine. Паролі під час запису не світи.

## Routines — як створити

Пиши **тому боту, який має це робити**, не «всім».

Шаблон:

```
Створи routine «[назва]».
Коли: [будні / неділя / п’ятниця] о [час] за Києвом.
Що робити: [skill або кроки].
Куди писати: у цей чат.
Якщо джерела немає — напиши збій, не підставляй старе.
Нічого не надсилати назовні без мого «так».
Спочатку test run.
```

Після створення: бот → **View conversation details → Routines** → Test run → якщо ок, залиш увімкненою. Можна паузити. Видалення без відміни. До 50 routines на бота.

Спочатку **дві**, не десять.

### 1. Координаторка — Ранковий бриф

```
Створи routine «Ранковий бриф».
Коли: будні о 7:00 за Києвом.
Зроби: подивись Календар, якщо підключений; статус Контенту / Продукту / UGC за вчора.
Формат:
✓ Календар → що сьогодні реально стоїть
✓ Гроші/продукт → один факт
✓ Контент → чи є сценарій на сьогодні
✓ UGC → чи є офер у роботі
Сьогодні треба від Каті: максимум 2 «так/ні». Все інше закрито.
Не пиши стратегію. Не публікуй. Якщо я на роботі — один наступний крок, який вміщається в 15 хвилин увечері.
Спочатку test run.
```

### 2. Координаторка — Підсумок тижня

```
Створи routine «Підсумок тижня».
Коли: п’ятниця о 19:00 за Києвом.
Три рядки: що зрушило гроші; що знято/заплановано; що гальмує.
Один фокус на наступний тиждень. Без нових ніш і без нових ботів.
Спочатку test run.
```

### 3а. Джирая — розвідка Threads (після одного ручного понеділка)

Пиши **в групі** або в чат Джирай:

```
Створи routine «Розвідка Threads».
Коли: понеділок о 10:00 за Києвом.
Знайди 10 публічних постів Threads з охопленням саме цього тижня.
Ніша: прокрастинація, «знаю але не роблю», видимість, робота 28–40.
На кожен: хук, каркас, гіпотеза чому залетіло, як лягає на Катю, TOFU чи MOFU.
Не копіюй текст. Не пиши фінальні пости.
Якщо платформу не відкриваєш — напиши «немає даних» і попроси скріни. Не вигадуй.
Спочатку test run.
```

### 3б. Іно — пакет Threads (після однієї ручної пачки)

```
Створи routine «Пакет Threads».
Коли: вівторок о 11:00 за Києвом.
Візьми каркаси Джирай і мікс Шикамару.
Зроби 12–14 постів голосом Каті (10 TOFU / 3 MOFU). Формат: 1–5 речень або короткий тред.
До кожного — 3 відповіді в першу годину.
BOFU не пиши (це Наруто). Не публікуй.
Спочатку test run.
```

### 3. Контент — пакет на тиждень (після того як 1 тиждень уже вийшов вручну)

```
Створи routine «Пакет Reels».
Коли: неділя о 18:00 за Києвом.
Джерела: Drive / Контекст Каті — бриф, воронка, план 14 днів, мова аудиторії.
Зроби: 7 слотів (5 TOFU Reels + 1 MOFU Reel + 1 карусель). На кожен — хук, кадри, Stories, CTA.
TikTok = ті самі Reels.
Не публікувати. Якщо план на 14 днів ще не доїхали — продовжуй серію, не вигадуй нову.
Спочатку test run.
```

### 4. UGC — офери (коли розвідка вже зроблена)

```
Створи routine «5 оферів».
Коли: понеділок о 20:00 за Києвом.
Знайди 5 реальних заявок фітнес/спорт/everyday. Таблиця: бренд, що знімати, дедлайн, гроші/бартер, посилання, варто/сміття.
Нічого не відправляй брендам. Чекай мого «так» на конкретний рядок.
Спочатку test run.
```

### 5. Інбокс — пізніше

```
Створи routine «Ранкова пошта».
Коли: будні о 7:20 за Києвом.
Gmail: 5 рядків ВАРТО, скільки шуму, які Skool-розсилки відписати.
Нічого не видаляй і не відповідай.
Спочатку test run.
```

### 6. Тренер — лише якщо хочеш нагадування, не автопілот залу

```
Щонеділі о 18:30 за Києвом напиши план на наступні 3 тренування одним аркушем кожне.
Не став діагнозів. Якщо я не відповіла про біль — питай, не вигадуй.
```

## Група «Контент-відділ»

Вона вже є, ліміт 6/6. Нову групу не збирай. Перепиши ролі: [kontent-viddil/README.md](kontent-viddil/README.md).

Перше повідомлення після перепису посад — у тому файлі (блок «Перше повідомлення в групу»).

Понеділок, щоб запустити тиждень:

```
Тиждень Threads-воронки.
@Джирая — 10 каркасів з охопленням цього тижня (або розбери мої скріни).
@Шикамару — після розвідки: 10 TOFU / 3 MOFU / 1 BOFU + 7 тем Сакурі.
@Іно — не стартуй, поки немає каркасів.
@Наруто — 1–2 BOFU, не купи.
@Сакура — чекай тем.
@Chief of Staff — пачка мені в середу на так/ні.
Ніхто не публікує.
```

`@` — коли один має робити. `@everyone` — рідко. Не клич усіх у кожне речення.

## Пам’ять («Memory updated»)

Після кожної правки, яка має жити далі:

```
Запам’ятай як правило: [одне речення].
```

Приклади, які тобі вже потрібні:

```
Запам’ятай: зовнішні дії тільки після мого «так».
Запам’ятай: публічно не говорити про мої гроші й борги.
Запам’ятай: TikTok = кроспост Instagram, без другого плану.
Запам’ятай: велику задачу ріж, інакше я її не візьму.
```

## Чого не робити

- Не став 8 routines в один вечір. Спочатку ранковий бриф + один пакет Контенту.
- Не проси «роби все як на скріні Sales». У тебе немає Salesforce і Sequencer — є Drive, Gmail, Календар, блог, UGC.
- Не давай боту слати пошту, постити, бронювати, купувати.
- Event-triggers (Slack/GitHub) тобі зараз не потрібні. Це шум.
- Test run — справжня робота. Дивись, чи зупинився перед «так».
