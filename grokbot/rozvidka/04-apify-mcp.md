# Apify у Grok Bot (не Claude, не Cowork)

Ті про-типи зі статті — для Claude. У Grok Bot ті самі дві речі робляться **інакше**. CSV руками не тягнемо.

| У статті | У тебе |
|---|---|
| Settings → Customize → Connectors → Add | **Grok Bot → Settings → Plugins → кастомний MCP** |
| Розклад у Cowork | **Routine в чаті бота «Розвідка»** |

Підключається **один раз** на акаунт. Усі боти бачать конектор. У чаті Розвідки вмикаєш `@Apify`.

---

## Раз: акаунт Apify

1. [apify.com](https://apify.com) → зареєструйся.
2. Поклади трохи грошей / картку. Прогін без токена **шукає** акторів, але **не знімає** пости.
3. Токен: Console → **Settings → API & Integrations → API token**. Поки що не копіюй у чат. Може знадобитись лише якщо Grok не відкриє вікно входу.

---

## Раз: конектор у Grok Bot

Не шлях Claude (`Customize → Connectors`). У Grok Bot:

1. Відкрий **Grok Bot → Settings → Plugins**.
2. Додай **кастомний MCP / custom connector** (не з маркетплейсу «Calendar»).
3. Ім’я: `Apify`
4. URL (краще з уже потрібними акторами, щоб бот не тягнув зайве):

```
https://mcp.apify.com?tools=actors,docs,apify/instagram-reel-scraper,futurizerush/meta-threads-scraper,streamers/youtube-scraper
```

Коротший варіант, якщо форма не любить довгий рядок:

```
https://mcp.apify.com
```

5. **Connect / Authorize.** Має відкритись браузер Apify — увійди і дозволь доступ.
6. Якщо Grok просить лише **ім’я + URL + headers** і вікна входу немає — у headers:

```
Authorization: Bearer ТВІЙ_ТОКЕН
```

Токен тільки в цьому полі. **Не в чат боту.**

7. У чаті **Розвідка**: напиши `@` → увімкни конектор **Apify**. Якщо `@` його не показує: Settings → Plugins → Yours → увімкни для цього бота.

Перевірка в чаті Розвідки:

```
@Apify Які в тебе зараз інструменти Apify? Не запускай жодного актора.
```

Має відповісти списком (search-actors / call-actor / конкретні скрейпери). Якщо «немає конектора» — крок 7 не зроблено.

## Раз: test run (ще без розкладу)

Список акаунтів уже в [akaunty.csv](akaunty.csv) або 8–12 лінків у тому ж повідомленні. Інакше зупинись.

```
@Apify Прожени тільки Instagram.
Актор: apify/instagram-reel-scraper.
Акаунти з akaunty.csv (IG), 8–12 Reels на акаунт, новіші за 14 днів.
Без відео і без транскрипту.
Сам забери результат через MCP. CSV мені не кидай.
Віддай 8–10 каркасів як у своїй картці.
Якщо актор упав — «немає даних», не вигадуй.
```

Те саме з `@Apify` і «тільки Threads» / «тільки YouTube» — окремими повідомленнями. Не в один прогін.

Якщо каркаси ок → «збережи цей процес як skill». Потім routine.

## Щотижня: Routine, не Cowork

Cowork у Claude тут немає. Розклад = **чат бота Розвідка**.

Спочатку один успішний ручний понеділок. Потім:

```
Створи routine «Свіжі каркаси тижня».
Коли: понеділок о 10:00 за Києвом.
Куди писати: у цей чат.

1) @Apify — Instagram (apify/instagram-reel-scraper), акаунти з akaunty.csv, 14 днів, без відео.
2) @Apify — Threads (futurizerush/meta-threads-scraper), акаунти або пошук з задачі Threads, 14 днів.
3) Відсій через about-me і audience.
4) Дві таблиці: 8–10 каркасів IG + 8–10 Threads. YouTube не чіпай, поки я не скажу.
5) Не пиши моїх постів. Не публікуй.
Якщо MCP або актор упав — один рядок «немає даних» і яка платформа. Не підставляй минулий тиждень.
Спочатку test run.
```

YouTube на щотижневий розклад не став — каналу ще немає. Кидай «прожени YouTube», коли треба.

Timezone у Settings = **Europe/Kyiv**.

## Якщо щось не їде

| Симптом | Що зробити |
|---|---|
| Немає пункту Connectors / Customize | Ти в Grok Bot. Іди в **Settings → Plugins** |
| Конектор зберігся, бот «не бачить Apify» | У чаті `@Apify`. Або Plugins → Yours → увімкни для Розвідки |
| Connect не відкриває Apify | Headers: `Authorization: Bearer …` з Console. Не в чат |
| Шукає акторів, пости не знімає | Немає оплати / токена. Анонімний MCP лише шукає в Store |
| Routine пише вигадані пости | Зніми розклад. Знову test run. «немає даних», не фантазія |
| Хоче скачати CSV | Скажи: забирай через MCP, файл мені не потрібен |

Локальний `npx @apify/actors-mcp-server` у Grok Bot **не** ставити. Бот сидить у хмарі, твій ноутбук йому не видно.
