# Розвідка: що реально чіпляє в ніші

Окремий бот **поза** групою «Контент-відділ». Не пише пости. Шукає публічні одиниці з охопленням і знімає **каркас**. Стратег кладе в Notion. Відділ пише вже свої тексти.

**У Grok цей бот не відмічено як створений** (стан на 30.08.2026). Є картка. Живий статус: [../stan.md](../stan.md).

Це не перехресний перепис шістки ролей. Джирая в групі лишається, поки Катя не скаже інакше.

## Чи працює ідея «окремо Threads, окремо Instagram, окремо YouTube»

**Так. Саме так і треба.** Не один запит «знайди все».

| | Один бот, три задачі | Три боти | Одна каша «шукай усе» |
|---|---|---|---|
| Працює? | Так | Так, але гірше | Ні |
| Навіщо | Різні актори Apify, різні метрики, різний формат каркаса | Ті самі правила тричі, голос роз’їдеться | Змішає Reels, треди і лонгріди в одну таблицю |

У Grok Bot задача / routine пишеться **в чат окремим повідомленням**. Три фрази = три задачі на одному боті.

Apify підключається **через MCP**, не через «скачай CSV». Кліки: [04-apify-mcp.md](04-apify-mcp.md). Це не Claude (`Customize → Connectors`) і не Cowork.

TikTok окремо не робимо: ті самі Reels.

## Чи працює план з Apify

Напрямок правильний. Сирий CSV сам по собі **не** відповідає «що чіпляє тих, для кого пишемо». План треба зібрати так:

1. Є **список акаунтів або запитів**, не «ніша взагалі». Actor Instagram Reel Scraper бере username / URL, не думку «мислення».
2. У Store — актор з рейтингом **і** великою місячною аудиторією, бажано від Apify, не лише «5.0 на 12 відгуках».
3. Запит на 5–10 акаунтів. Час частіше **3–15 хв**, не завжди 1–2.
4. Бот забирає рядки **сам через MCP**. Ти не скачуєш CSV. Він пропускає їх через [about-me.md](../about-me.md) і [audience.md](../audience.md) і віддає 8–10 каркасів.
5. Відео і транскрипти **не** вмикати за замовчуванням (дорого). Текст + перегляди / лайки / коментарі досить.

Платно, pay-per-result. Тижневий прогін без відео — зазвичай дрібні долари, не «безкоштовний Store».

## Які актори брати (перевірено в Store 29.08.2026)

| Задача | Актор | Чому цей |
|---|---|---|
| Instagram Reels з відомих акаунтів | [apify/instagram-reel-scraper](https://apify.com/apify/instagram-reel-scraper) | 4.36, ~10k міс., офіційний Apify. Caption, views, likes, comments, дата |
| Instagram пошук / кілька типів | [apify/instagram-scraper](https://apify.com/apify/instagram-scraper) | 4.73, ~41k міс. Якщо треба не лише Reels |
| Threads пости / пошук | [futurizerush/meta-threads-scraper](https://apify.com/futurizerush/meta-threads-scraper) | 4.19, ~1.6k міс., keyword + username, без логіну. Поле слабше за Instagram |
| YouTube канали / пошук | [streamers/youtube-scraper](https://apify.com/streamers/youtube-scraper) | 4.82, ~9.7k міс. Найстабільніша з трьох платформ |

Не брати першим: hashtag-scraper (рейтинг ~3.3), даунлодери відео, збір email, followers.

Threads-актори частіше падають (Meta). Якщо прогін порожній — бот пише «немає даних», не вигадує вірусні пости.

## Що бот не вміє без тебе

- Сам «знайти нішу» без списку в [akaunty.csv](akaunty.csv) або без 5–8 посилань у чаті.
- Зайти в приватне. Тільки публічне.
- Підключити Apify сам. Це робиш ти раз у **Settings → Plugins** (див. [04-apify-mcp.md](04-apify-mcp.md)). У маркетплейсі Grok готового «Apify» може не бути — це кастомний MCP `https://mcp.apify.com`.
