# Задача: розвідка Threads

Кинути боту **Розвідка** в чат. Окремо від Instagram.

## Actor

[futurizerush/meta-threads-scraper](https://apify.com/futurizerush/meta-threads-scraper)

Режим `search` + ключові з ніші **або** `usernames` з [akaunty.csv](akaunty.csv) де платформа = Threads.

Запити (українською, не «mindset»):
- знаю що робити але не роблю
- ще не готова
- загоняюсь
- відкладаю запуск
- сказала потім

`max_posts` = 40 на прогін. Вікно дат — цей тиждень / 14 днів.

Поле Threads слабше за Instagram: актори падають, цифр views може не бути. Тоді дивись відповіді й довжину гілки.

Офіційного Apify «Reel Scraper для Threads» немає. Не шукай близнюка Instagram-актора.

## Текст задачі / routine

```
Створи задачу «Розвідка Threads».
Коли я кажу «прожени Threads» або за розкладом (понеділок 10:00 Київ) — тільки після успішного test run.

1) Apify → futurizerush/meta-threads-scraper. Акаунти з akaunty.csv (Threads) і/або пошук: «знаю що робити але не роблю», «ще не готова», «загоняюсь», «відкладаю запуск».
2) Тільки публічне, це вікно (14 днів), до 40 постів.
3) Відсій війну, «підтримуючі» важкі пости, політику, терапію як референс.
4) 8–10 каркасів: хук, чи тред, каркас, гіпотеза, TOFU чи MOFU. BOFU з чужих продажів не брати.
Не копіюй текст. Не пиши моїх постів. Не змішуй з Instagram.
Якщо порожньо — «немає даних». Можу скинути 7–10 скрінів замість актора.
Спочатку test run.
```
