# 14 принципів у контент-відділі

Не новий конвеєр. Не сьомий бот. Та сама шістка, плюс лінза на тексти.

Повний скіл (кинути в чат): [../skill-perekonannia.md](../skill-perekonannia.md).  
На телефоні: [док у Drive](https://docs.google.com/document/d/1FVSfA-mRCDs0ef4jbZysmJDF7CzurIGmYr_0kT05IjM/edit). Шпаргалка: [Notion](https://app.notion.com/p/3cc4e56ef3568144abcff99af6f258c7).  
Наука лишається в playbook. Тут — **хто що робить**, щоб не розмазати всі 14 по кожному пості.

## Закон на всіх

1. Складай **2–3** принципи. Не спрей.
2. Перші 2 секунди / перший рядок = цікавість, відкрита петля або зрив автопілота.
3. Золотий ярус — фундамент. Втрата, «незакінчене пам’ятається», «одна жертва» — смак, і в нас ще урізані правилами.
4. Конкретика важливіша за трюк.
5. Голос Каті + «без слизу» нікуди не діваються.

## Хто за що відповідає

| Роль | Що робить з принципами | Чого не робить |
|---|---|---|
| **Джирая** | На кожен каркас: який принцип зібрав охоплення (гіпотеза). Беремо механіку, не текст. | Не пише фінальні пости «по Cialdini» |
| **Шикамару** | На тиждень — **одна** зв’язка на сюжет. Слотам пише 2–3 коди, не 14. | Не розписує лекцію психології в таблиці |
| **Іно** | Перший рядок Threads = #1/#2/#3. Легкість + сцена. Відповіді — взаємність (користь у репліці). | Не 14 прийомів у 4 реченнях |
| **Наруто** | Взаємність (ТЕСТ / серія в IG спочатку). Якір (2–10 хв vs ідеальний план). Правдивий дефіцит — лише коли набір реально закривається. | Не «останній шанс», не «ви втрачаєте», не «купи» до пілоту |
| **Сакура** | Reel: хук 0–3 сек з золотого ярусу; 3 хуки = 3 РІЗНІ принципи, не 3 синоніми; пік і кінець; історія = 60 сек до дії. | Не окрема «психо-стратегія» повз теми Шикамару |
| **Chief** | У середу ріже пачку: хук живий? 2–3 принципи? сцена є? сором/вигадані тисячі/фальшивий дефіцит — назад. | Не переписує пости замість авторок |

Зв’язка за замовчуванням (якщо Шикамару не вибрав іншу):

**зрив автопілота → цікавість → історія-сцена → конкретний доказ або якір → пік і кінець з мікродією.**

## Коди для таблиці Шикамару

Пиши коротко в колонці «робота поста» / нотатці слота:

| Код | Принцип | Коли |

| ЦІК | цікавість | майже кожен TOFU-хук |

| ЗРИ | зрив автопілота | дивний кадр / перший рядок не про нішу в лоб |
| ДОКАЗ | соцдоказ конкретний | сцена, день експерименту, реальний DM — не вигадані тисячі |

| ДЕФ | дефіцит | тільки правда |
| ВТР | втрата | рідко; тільки як кадр («тиждень з’їло»), не батіг |
| ЯКІР | якір | масштаб: план vs 2–10 хв |
| АВТ | авторитет практики | «Без прикрас», день N, не диплом |
| ІСТ | історія | сцена за 60 сек до поведінки |
| ЛЕГ | легкість | завжди; якщо важко сказати — ріж |
| ПІК | пік і кінець | обов’язково в Reel / карусель слайд 6–7 |
| ЗВИЧ | звичне обличчя | серія, «бачите мене знову» |
| КОНК | конкретика | завжди |

Норма слота: **2–3 коди**. Якщо Шикамару ставить 8 — Chief повертає.

## Що Chief бракує в середу (додаток до пачки)

На кожен фінальний текст Іно / Наруто / слот Сакури — три галочки, не есе:

```
Хук: ЦІК / ПЕТ / ЗРИ / мертвий
Склад: 2–3 / мало / спрей
Сцена: є кадр / абстракція
Червоне: сором-батіг / вигадані тисячі / фальшивий дефіцит / війна / борги Каті / діагноз
```

Якщо хук мертвий — не віддавай Каті «так/ні» на всю пачку. Верни Іно або Сакурі **один** новий хук.
