# Стан системи на 30.08.2026

Це остання правда. Якщо інший файл у `grokbot/` суперечить цьому — цей важливіший.

Розмова 30.08: таблиця для ботів → задача шефу з лінком і критеріями → Джирая = розвідка в групі 6/6 → перевірка «зроблено» → автомат банк → рілси без питання «які теми».

## Дві кімнати

- **Cursor** (репо `Kateryna-Truba`) — майстерня: правила, скіли, правки системи. Новий чат = одна задача. Не редагувати файли / Notion / Drive, поки Катя не сказала «зроби / запиши / дороби».
- **Grok Bot** — знімальний майданчик. Іменовані боти. Цей агент їх не запускає.

## Банк тем — колонки

Розвідка заповнює: Тема, Повнота (обрубок / є лінк / повна), Звідки (Threads / Reels / YouTube), Оригінал, Перший рядок, Дата, Статус = ідея, Нотатка.

Не чіпає: Біль ЦА, Старт, Як розкрити, Шар, Платформи, Вікно, Знімати як. Не затирає «я знайшла».

Один пост = один новий рядок. Обрубок ок.

Види: Банк, Розвідка, Ідеї, Обрубки, Повні, Я знайшла.

## Де шукати і що брати

Для кого: жінка 28–40, працює / своя справа, знає що робити і уникає. Не всі жінки. Не терапія.

**Threads:** пошук укр + рос (не mindset): знаю що робити але не роблю; ще не готова; загоняюсь; відкладаю запуск; сказала потім; все розумію нічого не змінюється. Насіння акаунтів немає.

**Reels:** спочатку theselfhelpplanner, calleighmc2, gracebrodeur, palna_anna, elyse_myers, chernyak.blog, milanias, malika.nikolaevaa, rina_momot, pagetkagy, jessijeanhome. Потім ширше той самий біль. Хештег «саморозвиток» ні.

**YouTube:** укр, рос **і англійська**. Пошук EN: I know what to do but I don't; not ready yet; procrastination at work; overthinking instead of starting. Каналів-насіння немає.

Брати: жива сцена «знаю — не роблю» / хук який зупиняє / сигнал цього вікна (14 днів, YT до місяця).

Не брати: війна як важіль, політика, терапія, діагноз, мотиваційний крик, «нова я», «енергія/ресурс/найкраща версія», сором як батіг.

Threads/Reels: EN лише механіка. YouTube: EN-теми можна.

Apify якщо є: Threads `futurizerush/meta-threads-scraper`, Reels `apify/instagram-reel-scraper`, YT `streamers/youtube-scraper`. Немає — «немає даних», не вигадувати.

## Рілси — колонки

Одиниця, Ідея (зв’язок на Банк), Формат = Reel, Хук 1/2/3, Сценарій, Кадри, Текст на екрані, Підпис, CTA (ТЕСТ / зберегти / серія / коментар), Статус (чернетка / можна знімати / не брати / знято).

Закон ролика: перші 2 сек зупиняють скрол; три хуки — різні, не синоніми; 20–40 сек хук → сцена → поворот → мікродія; голос Каті, ви; не коуч; не копія оригіналу; не «купи».

Сакура бере **всі** нові рядки дня. Не питає Катю. Дубль (вже є зв’язок) — пропустити.

## Межі бренду

Ніша: мислення, зміна поведінки. Не психолог / не коуч назовні.
BOFU = waitlist / ТЕСТ. Не «купи», поки немає пілоту.
Борги й доходи Каті назовні — ні. Війна як важіль — ні. Сором як тема — так; як батіг — ні. Її діагнози — якщо сама сказала; діагноз глядачці — ні. Не рівняти з зірками.
