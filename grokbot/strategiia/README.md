# Стратегія поза контент-відділом

Контент-група **не вигадує теми**. Вона бере рядки з Notion.

Стратег — окремий бот, не в групі «Контент-відділ».
Правда живе в Notion: банк на місяць, вікно на 2 тижні, статуси «знято / не знято».

Катя кидає тему в чат → стратег кладе рядок у таблицю.
Шеф відкриває ту саму таблицю і роздає Сакурі / Іно / Наруто / Джирай.

## Зробити сьогодні

1. Зайди на [notion.so](https://www.notion.so) і створи акаунт, якщо його немає. Простір лиши порожнім — таблиці руками не малюй.
2. Grok Bot → **Plugins** → **Notion** → Authorize. Якщо зависне — **Re-authenticate**, не Connect ще раз.
3. Створи бота стратегії (або винеси Шикамару з групи в окремий чат). Картка: [02-strateg.md](02-strateg.md).
4. Встав стартове повідомлення з картки. Він сам створить сторінку і базу та заповнить першим банком.
5. Перевір з телефону: база відкривається в додатку Notion, не лише в Grok.

Якщо бот не вміє створити базу — імпортуй CSV [bank-tem.csv](bank-tem.csv) у Notion: New page → Import → CSV.
