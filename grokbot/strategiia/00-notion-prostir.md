# Notion: банк тем (жива база)

Сторінка: [Катя — контент](https://app.notion.com/p/3cb4e56ef35681ebb59ef7520cdeebbf)  
База: [Банк тем](https://app.notion.com/p/619f329526ca44d5a000a6690a5366a7)  
Кроки для ботів: [Як заповнювати банк тем](https://app.notion.com/p/3cc4e56ef356819db10ac35c592c6662)

Одна купа тем. Результат розвідки — **нові рядки тут**. Не в чат. Не в «Банк тем — живі». Хуки й сценарії сюди не писати.

## Колонки

| Колонка | Тип | Хто | Як |
|---|---|---|---|
| Тема | Title | усі | Два речення, якщо є. Обрубок теж ок |
| Повнота | Select | розвідка | обрубок / є лінк / повна |
| Звідки | Select | усі | Threads / Reels / YouTube / я знайшла / біль / інтерв’ю |
| Оригінал | URL | розвідка | Лінк на пост або відео |
| Перший рядок | Text | розвідка | Цитата хука, не переказ |
| Дата | Date | розвідка | Коли знайшла |
| Статус | Select | розвідка ставить ідея | далі стратег / Катя |
| Біль ЦА | Text | ЦА | Словами людей. Розвідка не чіпає |
| Старт | Select | ЦА або Катя | YT / IG / Threads / ще не ясно |
| Як розкрити | Text | ЦА | Одне-два речення. Розвідка не чіпає |
| Нотатка | Text | усі | Коротке, не сценарій |
| Шар / Платформи / Вікно / Знімати як | — | не розвідка | за потреби |

## Хто що кладе

**Розвідка:** новий рядок. Статус = ідея. Звідки = Threads / Reels / YouTube. Не вигадує теми. Не заповнює Біль ЦА, Старт, Як розкрити. Не затирає «я знайшла».

**ЦА:** Біль ЦА + Старт + Як розкрити. В API не ходить.

**Катя:** речення → Звідки = я знайшла. Бот не переписує.

## Види

Банк, Розвідка, Ідеї, Обрубки, Повні, Я знайшла, канбан по статусу, Вікно 2 тижні, Зняти сьогодні, Банк місяця.
