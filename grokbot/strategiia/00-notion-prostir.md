# Порожній Notion: що має з’явитись

Один простір. Не десять баз.

**Сторінка:** `Катя — контент`  
**База:** `Банк тем`

## Властивості бази

| Колонка | Тип | Значення |
|---|---|---|
| Тема | Title | одним рядком, як знімати |
| Шар | Select | TOFU / MOFU / BOFU |
| Платформи | Multi-select | IG / Threads / TikTok / TG / YT |
| Статус | Select | ідея / банк місяця / вікно 2 тижні / можна знімати / знято / опубліковано / відкладено |
| Знімати як | Select | вдома / зал / дорога / тільки голос / карусель |
| Звідки | Select | ЦА / експеримент 14д / Катя кинула / соцмережі |
| Вікно | Select | тиждень 1 / тиждень 2 / пізніше в місяці |
| Нотатка | Text | хук або заборона (без боргів, війни, діагнозів) |

TikTok у рядку з IG означає: той самий Reel, поки Катя вчиться знімати. Окремий сценарій не потрібен.

BOFU зараз: waitlist / «напиши ТЕСТ» / «йди в Instagram». Не «купи канал».

## Види (views)

1. **Канбан** — групування по Статус
2. **Вікно 2 тижні** — фільтр: статус = вікно 2 тижні або можна знімати
3. **Зняти сьогодні** — фільтр: можна знімати
4. **Банк місяця** — все, що ще не у вікні

Катя не затверджує стратегію щотижня. Раз на два тижні дивиться вид «Вікно 2 тижні» і каже: ці знімаю, оці пізніше.
