Сторінка: [Катя — контент](https://app.notion.com/p/3cb4e56ef35681ebb59ef7520cdeebbf)

Одна купа тем. Результат розвідки — **нові рядки тут**. Не в чат. Не в «Банк тем — живі».

Хуки й сценарії сюди можна писати **тільки** для рядків, які я сама позначила «Готую цей тиждень» — свої ідеї, які веду через 4 кроки. Для чужих каркасів (розвідка) ці колонки лишаються порожні.

## Колонки: власний сценарій (заповнюють я і Сакура, 4 кроки)

Ідея → сценарій — не окрема таблиця, той самий рядок. Процес: [../protsess-stsenariiv.md](../protsess-stsenariiv.md).

| Колонка | Тип | Хто | Як |
|---|---|---|---|
| Готую цей тиждень | Checkbox | я | Позначаю, які ідеї (свої «я знайшла» або чужі каркаси розвідки) веду в роботу зараз. Сакура дивиться тільки на позначені |
| Формат контенту | Select | Сакура | Reel / карусель. Якщо Катя не сказала інакше — Reel. Одна ідея — і Reel, і карусель? Дублює рядок (Notion → Duplicate), змінює формат у копії |
| Формат зйомки | Select | Сакура | за замовчуванням `yap-відео / talking head`; альтернативи: `voice-over + B-roll` / `демонстрація / процес` / `лайф-сцена`. Вибирає до кроку 2, щоб зі сценарію було ясно, що саме знімати |
| Теги | Multi-select | Сакура | стовпи з [about-me.md](../about-me.md): Петлі в голові / Уникання і «потім» / Відповідальність за стан / Реакція / Впевненість з доказів / Дія в низькій енергії |
    20|| Головна думка (крок 1) | Text | Сакура, підтверджено мною | коротка перевірка одразу після брейндампу, до повного сценарію |
| Хук (крок 1) | Text | Сакура, підтверджено мною | той самий чек-запит |
| Статус сценарію | Select | Сакура | чекає брейндампу / крок 1 підтверджено / крок 2 чернетка / крок 3 мій голос / крок 4 записано / знято |
| Сценарій | Text (довгий) | Сакура → я | повний текст після кроку 3. Хуки/прийоми/слайди по кадрах усередині — окрема розмова, коли до неї дійдемо |

«Статус сценарію» окремий від «Статус» вище — той про долю ідеї (розвідка → стратег/Катя), цей про те, на якому кроці сценарій.

Окремий Select «Тема» як категорію **не додаємо**. У базі `Тема` — обов'язкове Title-поле і коротка впізнавана назва рядка. Для категоризації достатньо `Теги`; не заводимо два поля з тим самим змістом.

## Хто що кладе

**Розвідка:** новий рядок. Статус = ідея. Звідки = Threads / Reels / YouTube. Не вигадує теми. Не заповнює Біль ЦА, Старт, Як розкрити, і не чіпає колонки сценарію. Не затирає «я знайшла».

**ЦА:** Біль ЦА + Старт + Як розкрити. В API не ходить.

**Катя:** речення → Звідки = я знайшла. Бот не переписує. Готую цей тиждень → так, коли готова робити сценарій.

**Сакура:** тільки рядки з «Готую цей тиждень» = так. Веде їх через 4 кроки, пише в колонки сценарію. Чужі каркаси розвідки (Готую цей тиждень = ні) не чіпає.

## Види

Банк, Розвідка, Ідеї, Обрубки, Повні, Я знайшла, канбан по статусу, Вікно 2 тижні, Зняти сьогодні, Банк місяця, **Готую цей тиждень** (фільтр по чекбоксу — це і черга Сакури).
